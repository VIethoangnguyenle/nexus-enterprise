# Plans (archived)

> **Frozen.** The workflow axis moved from superpowers to AgentKit (see CLAUDE.md §4). New plans
> are written by `ak:plan` into `plans/<timestamp>-<slug>/`. The files here are kept as history.

Implementation plans written by `superpowers:writing-plans`, one file per feature, named
`YYYY-MM-DD-<feature>.md`.

A plan is working memory: it is executed and then it is history. The durable record of what the
system does lives in `docs/specs/`. Any plan that changes system behaviour names the capability
it adds or modifies, and that spec is updated when the plan lands.
